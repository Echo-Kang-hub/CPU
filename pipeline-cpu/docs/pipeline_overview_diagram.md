# 流水线 CPU 总体设计框架图 — AI 绘图提示词

生成一张高层次流水线架构框图，图中不要写标题。

---

## 整体布局

五个大方块从左到右依次排列，代表五个流水级。每个方块内部写阶段名和简要功能关键词。方块之间用粗箭头连接，箭头上标注传递的数据总线名和位宽。底部画一条反馈线从 WB 回到 ID，标注"写回"。

---

## 五个流水级方块（从左到右，统一浅蓝色背景）

### 1. IF — 取指
- 标签: **IF**
- 内部关键词: PC, NPC, 指令存储器
- 底部小字: 取指令、计算下一PC

### 2. ID — 译码
- 标签: **ID**
- 内部关键词: RF, EXT, ctrl, hazard_detect
- 底部小字: 指令译码、寄存器读、分支判断

### 3. EX — 执行
- 标签: **EX**
- 内部关键词: ALU, forwarding
- 底部小字: 算术逻辑运算、地址计算

### 4. MA — 访存
- 标签: **MA**
- 内部关键词: dmem, CSR写入
- 底部小字: 数据存储器读写、CSR操作

### 5. WB — 写回
- 标签: **WB**
- 内部关键词: 写回选择
- 底部小字: 结果写回寄存器文件

---

## 级间连线标注（箭头从左到右）

| 连线 | 标注 |
|------|------|
| IF → ID | IF_to_ID_bus [64 bit] |
| ID → EX | ID_to_EX_bus [233 bit] |
| EX → MA | EX_to_MA_bus [153 bit] |
| MA → WB | MA_to_WB_bus [104 bit] |

每条连线旁边画一个小方块，写 "流水线寄存器"。

---

## 旁路/冒险路径（用虚线或不同颜色的箭头）

1. **EX 转发路径**: 从 EX 底部画一条虚线回到 EX 自身的 ALU 输入，标注 "Forward_EXMA / Forward_MAWB"，颜色：橙色
2. **MA 转发路径**: 从 MA 底部画一条虚线回到 EX，标注 "EXMA 数据"，颜色：橙色
3. **WB 写回路径**: 从 WB 底部画一条粗虚线回到 ID 的 RF 写端口，标注 "写回数据 [32 bit] + rd[4:0] + RegWrite"，颜色：红色
4. **分支/跳转反馈**: 从 ID 顶部画一条虚线弧回到 IF，标注 "Branch/Jal/Jalr/mret"，颜色：紫色
5. **中断信号**: 从图的上方画一条虚线进入 IF，标注 "ext_interrupt → interrupt_taken"，颜色：红色

---

## 底部注释区

在图的底部，用一行小字列出：
- 握手协议: valid / allowin
- 冲刷: FLUSH_IFID（分支/跳转/中断时清除 IF/ID 寄存器）
- 停顿: stall（load-use / ALU-branch / load-branch / ALU-CSR 时暂停 ID 级）
